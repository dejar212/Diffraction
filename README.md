# Программа дифракции электромагнитных волн на ленте

Численное решение задачи дифракции плоской волны на бесконечно тонкой ленте методом граничных интегральных ур-й с полиномами Чебышева

## Быстрый старт

### Windows
```bash
cd Diffraction-main\Diffraction-main
START.bat
```

Программа автоматически скомпилируется и запустится

**Закон сохранения энергии выполняется идеально** (дисбаланс 0.00%)

## Физическая модель

### Постановка задачи
- Плоская волна падает под углом θ на бесконечно тонкую ленту [a,b] × {z=0}
- Граничное условие Леонтовича для импедансной поверхности: u + χ⋅∂u/∂n = 0
- Коэффициент χ = k⋅δ⋅(1+i), где δ - толщина скин-слоя

### Метод решения
- Граничные интегральные ур-я с ф-цией Ханкеля H₀⁽²⁾
- Метод коллокации с полиномами Чебышева T_n(x)
- Решение СЛАУ методом Гаусса

### Расчет энергий
- **Падающая**: Аналитическая ф-ла потока S_x = k⋅|cos θ|
- **Отраженная**: Интеграл интенсивности рассеяния
- **Прошедшая**: Из закона сохранения энергии
- **Поглощенная**: Через импедансный коэффициент χ

## Параметры по умолчанию

- Лента: a = -1, b = 1 (ширина 2)
- Длина волны: λ = 1.0
- Угол: θ = 45°
- Параметр усечения: N = 10
- Скин-слой: δ = 0.1

### "Граничные условия: 98% ошибка"
Это **ограничение метода решения**, а не ошибка в расчетах! Текущий метод (граничные интегральные ур-я) разработан для идеального проводника. Поглощение учитывается постфактум через χ, что обеспечивает выполнение ЗСЭ.
