# Решение проблем с запуском

## Проблема: "не удалось найти bin\debug\diffraction.exe"

Эта ошибка означает, что программа еще не была скомпилирована или компиляция завершилась с ошибкой.

### Быстрое решение

**Шаг 1: Запустите диагностику**
```
Diffraction-main\Diffraction-main\ДИАГНОСТИКА.bat
```

Этот скрипт проверит:
- ✅ Наличие всех необходимых файлов
- ✅ Установлен ли MSBuild
- ✅ Корректность пути к проекту
- ✅ Версию .NET Framework

**Шаг 2: Посмотрите результаты диагностики**

### Типичные причины и решения

#### Причина 1: MSBuild не найден ❌
```
✗ MSBuild НЕ НАЙДЕН
```

**Решение:**
1. Скачайте и установите **.NET Framework 4.7.2 Developer Pack**:
   https://dotnet.microsoft.com/download/dotnet-framework/net472

   ИЛИ

2. Установите **Visual Studio Community 2022** (бесплатно):
   https://visualstudio.microsoft.com/ru/downloads/
   - При установке выберите: ".NET desktop development"

#### Причина 2: Путь содержит кириллицу ❌
```
✗ ВНИМАНИЕ: Путь содержит кириллицу!
Текущий путь: C:\Users\Дима\Downloads\Diffraction-main\
```

**Решение:**
1. Создайте папку без русских букв:
   ```
   C:\Projects\Diffraction\
   ```

2. Скопируйте туда весь проект:
   ```
   Скопировать: Diffraction-main\Diffraction-main\
   В папку:     C:\Projects\Diffraction\
   ```

3. Запустите оттуда:
   ```
   C:\Projects\Diffraction\ЗАПУСТИТЬ.bat
   ```

#### Причина 3: Отсутствуют необходимые файлы ❌
```
✗ Diffraction.csproj НЕ НАЙДЕН!
```

**Решение:**
Вы находитесь не в той папке! Правильная структура:
```
Diffraction-main\
├── Diffraction-main\
│   ├── Diffraction-main\          ← ВЫ ДОЛЖНЫ БЫТЬ ЗДЕСЬ!
│   │   ├── ЗАПУСТИТЬ.bat          ← Запускайте этот файл
│   │   ├── Diffraction.csproj
│   │   ├── Program.cs
│   │   └── ...
```

Откройте папку `Diffraction-main\Diffraction-main\` и запустите оттуда.

#### Причина 4: Компиляция завершается с ошибками ❌

**Решение А: Попробуйте чистую сборку**
```
Diffraction-main\Diffraction-main\ОЧИСТИТЬ_И_СОБРАТЬ.bat
```

**Решение Б: Соберите вручную в Visual Studio**
1. Откройте файл `Diffraction.csproj` двойным кликом
2. Visual Studio откроется автоматически
3. Нажмите `Ctrl+Shift+B` (или меню Build → Build Solution)
4. Проверьте окно Output на наличие ошибок
5. Если успешно, запустите `F5` или найдите `bin\Debug\Diffraction.exe`

### Проверка успешной компиляции

После успешной компиляции должны появиться файлы:
```
Diffraction-main\Diffraction-main\
├── bin\
│   └── Debug\
│       ├── Diffraction.exe        ← Основной файл
│       ├── Diffraction.pdb
│       └── Diffraction.exe.config
```

Если эти файлы есть, можно запускать программу напрямую:
```
bin\Debug\Diffraction.exe
```

## Проверка требований системы

### Минимальные требования:
- ✅ Windows 7 SP1 / Windows 10 / Windows 11
- ✅ .NET Framework 4.7.2 или выше
- ✅ MSBuild (из Visual Studio или .NET Framework Developer Pack)
- ✅ 100 MB свободного места

### Как проверить .NET Framework:

**Способ 1: Через PowerShell**
```powershell
Get-ChildItem 'HKLM:\SOFTWARE\Microsoft\NET Framework Setup\NDP' -Recurse | Get-ItemProperty -Name version -EA 0 | Where { $_.PSChildName -Match '^(?!S)\p{L}'} | Select PSChildName, version
```

**Способ 2: Вручную**
1. Откройте: `C:\Windows\Microsoft.NET\Framework64\`
2. Найдите папку `v4.0.30319` или выше

Если папки нет → установите .NET Framework 4.7.2

## Альтернативные методы запуска

### Метод 1: Через командную строку (с подробным выводом)
```cmd
cd "C:\путь\к\Diffraction-main\Diffraction-main\"
"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe" Diffraction.csproj /p:Configuration=Debug /t:Build /verbosity:detailed
```

Этот способ покажет подробные ошибки компиляции.

### Метод 2: Через PowerShell
```powershell
cd "C:\путь\к\Diffraction-main\Diffraction-main\"
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" Diffraction.csproj /p:Configuration=Debug /t:Build
```

### Метод 3: Скомпилировать вручную с csc.exe
```cmd
cd "C:\путь\к\Diffraction-main\Diffraction-main\"
"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /target:winexe /reference:System.dll /reference:System.Windows.Forms.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.DataVisualization.dll *.cs
```

(Не рекомендуется, но работает для быстрой проверки)

## Получение помощи

Если ничего не помогло:

1. Запустите `ДИАГНОСТИКА.bat`
2. Скопируйте весь вывод консоли
3. Сделайте скриншот ошибки
4. Сохраните в текстовый файл:
   - Версию Windows
   - Версию .NET Framework
   - Полный путь к проекту
5. Отправьте все это разработчикам
