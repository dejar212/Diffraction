# Теория дифракции электромагнитных волн на импедансной ленте

## 1. Постановка задачи

Рассматривается задача дифракции плоской электромагнитной волны на бесконечно тонкой импедансной ленте, расположенной в плоскости $z = 0$ на отрезке $[a, b]$ оси $x$

### 1.1. Падающее поле

Плоская волна, падающая под углом $\theta$ к оси $x$, описывается ф-цией

$$u_0(x, z) = e^{ik(x\cos\theta + z\sin\theta)}$$

где $k = \frac{2\pi}{\lambda}$, волновое число, $\lambda$, длина волны

### 1.2. Граничное условие Леонтовича

На импедансной поверхности выполняется граничное условие Леонтовича

$$u + \chi \frac{\partial u}{\partial n} = 0 \quad \text{на } z = 0, \, x \in [a,b]$$

где $\chi$, импедансный коэффициент, $n$, нормаль к поверхности (направление оси $z$)

Для проводника со скин-эффектом

$$\chi = k\delta(1 + i)$$

где $\delta$, толщина скин-слоя

Физический смысл: $\chi$ описывает отношение тангенциальных компонент электрического и магнитного полей на поверхности проводника

### 1.3. Уравнение Гельмгольца

В свободном пространстве поле $u(x,z)$ удовлетворяет ур-ю Гельмгольца

$$\Delta u + k^2 u = 0$$

где $\Delta = \frac{\partial^2}{\partial x^2} + \frac{\partial^2}{\partial z^2}$, оператор Лапласа

### 1.4. Условия излучения

На бесконечности поле должно удовлетворять условиям излучения Зоммерфельда т.е. рассеянное поле $u_{\text{рас}} = u - u_0$ должно представлять собой расходящуюся волну

$$u_{\text{рас}} \sim \frac{e^{ikr}}{\sqrt{r}}, \quad r \to \infty$$

## 2. Метод граничных интегральных ур-й

### 2.1. Интегральное представление решения

Решение задачи дифракции ищется в виде интеграла

$$u(x,z) = u_0(x,z) + \frac{i}{4} \int_a^b \varphi(t) H_0^{(2)}(k|r - r'|) \, dt$$

где:
- $H_0^{(2)}$, ф-ция Ханкеля 2-го рода нулевого порядка
- $r = (x,z)$, $r' = (t,0)$, точки наблюдения и интегрирования
- $\varphi(t)$, неизвестная плотность распределения источников на ленте

### 2.2. Функция Ханкеля

Ф-ция Ханкеля 2-го рода выражается через ф-ции Бесселя

$$H_0^{(2)}(x) = J_0(x) - iN_0(x)$$

где:
- $J_0(x)$, ф-ция Бесселя 1-го рода нулевого порядка
- $N_0(x)$, ф-ция Неймана (Бесселя 2-го рода)

Функция $H_0^{(2)}$ является фундаментальным р-нием ур-я Гельмгольца в 2D

$$\Delta H_0^{(2)}(k|r-r'|) + k^2 H_0^{(2)}(k|r-r'|) = -\frac{4i}{\pi}\delta(r-r')$$

### 2.3. Функция Бесселя $J_0(x)$

Ф-ция Бесселя 1-го рода вычисляется через степенной ряд

$$J_0(x) = \sum_{n=0}^{\infty} \frac{(-1)^n}{(n!)^2} \left(\frac{x}{2}\right)^{2n}$$

Реализация в программе использует итерационный алгоритм с критерием сходимости $|s_n| < \varepsilon$, где $\varepsilon = 10^{-4}$

### 2.4. Функция Неймана $N_0(x)$

Ф-ция Неймана выражается через $J_0(x)$ и вспомогательную ф-цию

$$N_0(x) = \frac{2}{\pi}\left(J_0(x)\ln\frac{x}{2} + Y_0(x)\right)$$

где

$$Y_0(x) = \sum_{n=1}^{\infty} \frac{(-1)^n}{(n!)^2} \left(\frac{x}{2}\right)^{2n} \psi_n$$

$$\psi_n = -\gamma + \sum_{k=1}^n \frac{1}{k}$$

$\gamma \approx 0.57721566$, постоянная Эйлера

## 3. Метод коллокации

### 3.1. Разложение по полиномам Чебышева

Неизвестная плотность $\varphi(t)$ раскладывается по полиномам Чебышева 1-го рода

$$\varphi(t) = \sum_{i=0}^{N-1} y_i T_i^{[a,b]}(t)$$

где $T_i^{[a,b]}(t)$, полином Чебышева $i$-го порядка, перенормированный на отрезок $[a,b]$

$$T_i^{[a,b]}(t) = T_i\left(\frac{2t - a - b}{b - a}\right)$$

Полиномы Чебышева определяются рекуррентно

$$T_0(x) = 1, \quad T_1(x) = x$$

$$T_{n+1}(x) = 2xT_n(x) - T_{n-1}(x)$$

### 3.2. Квадратурная ф-ла

Интегралы вычисляются по квадратурной ф-ле Гаусса-Чебышева

$$\int_a^b f(t) T_j^{[a,b]}(t) \, dt \approx \frac{\pi(b-a)}{2M} \sum_{m=0}^{M-1} f(t_m) T_j^{[a,b]}(t_m)$$

где узлы $t_m$ выбираются как корни полинома $T_M(x)$

$$t_m = \frac{b-a}{2}\cos\left(\frac{2m+1}{2M}\pi\right) + \frac{b+a}{2}$$

### 3.3. Система линейных алгебраических ур-й (СЛАУ)

Подставляя разложение в граничное условие и применяя метод коллокации, получаем СЛАУ

$$\sum_{j=0}^{N-1} A_{kj} y_j = B_k, \quad k = 0,1,\ldots,N-1$$

где

$$A_{kj} = \frac{\pi^2}{M^2} \sum_{m=0}^{M-1} \sum_{n=0}^{M-1} r(t_n, t_m) T_j^{[a,b]}(t_n) T_k^{[a,b]}(t_m) + R_k \delta_{kj}$$

$$B_k = \frac{\pi}{M} \sum_{m=0}^{M-1} f(t_m) T_k^{[a,b]}(t_m)$$

$$f(x) = -2\pi u_0(x, 0) = -2\pi e^{ikx\cos\theta}$$

### 3.4. Регуляризация

Для устранения сингулярности диагональные элементы матрицы регуляризуются

$$R_0 = \pi^2 \ln(b - a)$$

$$R_k = \frac{\pi^2}{2(k+1)}, \quad k \geq 1$$

Эти члены устраняют логарифмическую особенность ядра $H_0^{(2)}$ при $r \to r'$

### 3.5. Ядро интегрального ур-я

Ядро $r(t,x)$ имеет вид

$$r(t,x) = \begin{cases}
\frac{\pi i}{2} J_0(k|t-x|) + \left(J_0(k|t-x|) - 1\right)\ln\frac{k|t-x|}{2} + \ln\frac{k}{2} + Y_0(k|t-x|), & |t-x| > \varepsilon \\
\frac{\pi i}{2} J_0(0) + \ln\frac{k}{2} + Y_0(0), & |t-x| \leq \varepsilon
\end{cases}$$

где $\varepsilon = 10^{-8}$, малая величина для обработки сингулярности

Знак минус перед $r(t,x)$ в программе:

$$r(t,x) \to -r(t,x)$$

связан с выбором нормировки и направлением нормали

## 4. Решение СЛАУ методом Гаусса

Полученная СЛАУ решается методом Гаусса с выбором главного элемента

### 4.1. Прямой ход

На каждом шаге $i = 0,\ldots,N-2$ выбирается максимальный по модулю элемент в столбце $i$ строк $i,\ldots,N-1$

$$\max_{k=i,\ldots,N-1} |A_{ki}| = |A_{mi}|$$

Строки $i$ и $m$ меняются местами

Затем выполняется исключение

$$A_{jk} \gets A_{jk} - \frac{A_{ji}}{A_{ii}} A_{ik}, \quad j > i, \, k > i$$

$$B_j \gets B_j - \frac{A_{ji}}{A_{ii}} B_i, \quad j > i$$

### 4.2. Обратный ход

Вычисляются неизвестные $y_k$ начиная с последней

$$y_{N-1} = \frac{B_{N-1}}{A_{N-1,N-1}}$$

$$y_i = \frac{1}{A_{ii}}\left(B_i - \sum_{j=i+1}^{N-1} A_{ij}y_j\right), \quad i = N-2,\ldots,0$$

### 4.3. Проверка устойчивости

Если $|A_{ii}| < \varepsilon_{\text{pivot}}$ (где $\varepsilon_{\text{pivot}} = 10^{-12}$), матрица считается вырожденной и метод возвращает код ошибки

## 5. Вычисление полного поля

После нахождения коэффициентов $y_i$ полное поле вычисляется как

$$u(x,z) = u_0(x,z) + \frac{i}{4} \sum_{i=0}^{N-1} y_i \int_a^b T_i^{[a,b]}(t) H_0^{(2)}(k\rho) \, dt$$

где $\rho = \sqrt{(x-t)^2 + z^2}$

Интеграл вычисляется квадратурой

$$\int_a^b T_i^{[a,b]}(t) H_0^{(2)}(k\rho) \, dt \approx \frac{\pi}{M} \sum_{m=0}^{M-1} T_i^{[a,b]}(v_m) H_0^{(2)}(k\rho_m)$$

где $v_m$, узлы Гаусса-Чебышева, $\rho_m = \sqrt{(x-v_m)^2 + z^2}$

## 6. Энергетический баланс

### 6.1. Закон сохранения энергии (ЗСЭ)

Полная энергия падающей волны должна равняться сумме отраженной, прошедшей и поглощенной энергий

$$E_{\text{пад}} = E_{\text{отр}} + E_{\text{прош}} + E_{\text{погл}}$$

### 6.2. Падающая энергия

Для плоской волны поток энергии через вертикальную линию

$$E_{\text{пад}} = \int_{-L}^{L} S_x^{(0)} \, dz = k|\cos\theta| \cdot 2L$$

где $L$, высота области интегрирования, $S_x^{(0)} = k|\cos\theta|$, плотность потока энергии падающей волны

В программе $L = 3(b-a)$

### 6.3. Отраженная энергия

Отраженная энергия вычисляется как интеграл интенсивности рассеянного поля слева от ленты

$$E_{\text{отр}} = \alpha \int_{-L}^{L} |u_{\text{рас}}(x_{\text{л}}, z)|^2 \, dz$$

где $x_{\text{л}} = a - \frac{b-a}{2}$, координата линии измерения

$\alpha = \frac{k|\cos\theta|}{2\pi}$, масштабный множитель для согласования размерностей

### 6.4. Прошедшая энергия

Прошедшая энергия вычисляется из закона сохранения

$$E_{\text{прош}} = E_{\text{пад}} - E_{\text{отр}} - E_{\text{погл}}$$

Это гарантирует математически точное выполнение ЗСЭ

### 6.5. Поглощенная энергия

Для импедансной поверхности поглощенная энергия

$$E_{\text{погл}} = \int_a^b P(x) \, dx$$

где $P(x)$, плотность поглощенной мощности на единицу длины

$$P(x) = \text{Re}(\chi) \left(|u(x,0)|^2 + k\left|\frac{\partial u}{\partial z}(x,0)\right|^2\right)$$

В программе используется масштабирование

$$E_{\text{погл}} = \frac{k}{4\pi(b-a)} \sum_{m=0}^{M-1} \text{Re}(\chi)\left(|u(x_m,0)|^2 + k\left|\frac{\partial u}{\partial z}(x_m,0)\right|^2\right) \Delta x$$

где $x_m = a + (m+0.5)\Delta x$, $\Delta x = \frac{b-a}{M}$

Производная вычисляется численно

$$\frac{\partial u}{\partial z}(x,0) \approx \frac{u(x,\delta z) - u(x,0)}{\delta z}$$

где $\delta z = \frac{\lambda}{500}$

## 7. Проверка точности решения

### 7.1. Граничное условие Леонтовича

Погрешность выполнения граничного условия

$$\varepsilon_{\text{гр}} = \frac{1}{M+1} \sum_{i=0}^M \frac{|u(x_i,0) + \chi \frac{\partial u}{\partial z}(x_i,0)|}{\max(|u(x_i,0)|, 0.1)}$$

где $x_i = a + i\frac{b-a}{M}$

Погрешность зависит от N и параметра $\chi$

### 7.2. Уравнение Гельмгольца

Невязка ур-я Гельмгольца в свободном пространстве

$$\varepsilon_{\text{Гельм}} = \frac{|\Delta u(x_0,z_0) + k^2 u(x_0,z_0)|}{k^2|u(x_0,z_0)| + 10^{-10}}$$

где $(x_0,z_0) = (b + \lambda, \lambda)$, контрольная точка вне ленты

Лапласиан вычисляется численно с шагом $h = \frac{\lambda}{100}$

$$\Delta u \approx \frac{u(x+h,z) + u(x-h,z) + u(x,z+h) + u(x,z-h) - 4u(x,z)}{h^2}$$

### 7.3. Энергетический баланс

Дисбаланс энергии

$$\varepsilon_{\text{эн}} = \frac{|E_{\text{пад}} - (E_{\text{отр}} + E_{\text{прош}} + E_{\text{погл}})|}{E_{\text{пад}}}$$

В текущей реализации $\varepsilon_{\text{эн}} = 0$ т.к. $E_{\text{прош}}$ вычисляется из ЗСЭ

## 8. Численная реализация

### 8.1. Параметры дискретизации

- $N$, кол-во членов разложения Чебышева (по умолчанию 10)
- $M$, кол-во узлов квадратуры (по умолчанию 20)
- $M_{\text{эн}}$, кол-во точек для интегралов энергии (100)
- $M_{\text{погл}}$, кол-во точек для поглощения (200)

### 8.2. Сложность алгоритма

- Формирование матрицы: $O(N^2 M^2)$
- Решение СЛАУ: $O(N^3)$
- Вычисление поля: $O(NM)$ на одну точку
- Общая сложность: $O(N^2 M^2 + N^3)$

При $N = 10$, $M = 20$: $\sim 40000$ операций для формирования матрицы + $1000$ для решения

### 8.3. Точность вычислений

- Полиномы Чебышева: машинная точность ($\sim 10^{-15}$)
- Функции Бесселя: $\varepsilon = 10^{-4}$ (ряд до 10000 членов)
- Квадратуры: $O(M^{-2})$ для гладких ф-ций
- Решение СЛАУ: машинная точность с пивотингом

## 9. Учет скин-эффекта

### 9.1. Ограничение метода

Интегральное ур-е с ядром $H_0^{(2)}$ разработано для условия $u = 0$ на ленте (идеальный проводник)

Для импедансного условия Леонтовича $u + \chi \frac{\partial u}{\partial n} = 0$ необходима модифицированная ф-ция Грина, удовлетворяющая

$$G + \chi \frac{\partial G}{\partial n} = 0$$

Построение такой ф-ции Грина для ленты конечной ширины требует вычисления интеграла Зоммерфельда, что существенно усложняет реализацию

### 9.2. Приближенный учет

При $k\delta \ll 1$ (малая толщина скин-слоя) решение для идеального проводника является хорошим приближением

Поглощение энергии учитывается постфактум через коэффициент $\chi$

$$E_{\text{погл}} = \frac{k}{4\pi(b-a)} \int_a^b \text{Re}(\chi)\left(|u|^2 + k\left|\frac{\partial u}{\partial z}\right|^2\right) dx$$

### 9.3. Область применимости

1. $k\delta \ll 1$ (малая толщина скин-слоя)
2. $k(b-a) \sim 1$ (ширина ленты порядка длины волны)
3. $10 \leq N \leq 20$ (число членов разложения)

## 10. Выводы

1. Метод корректно решает задачу дифракции на ленте для идеального проводника
2. Граничное условие $u=0$ выполняется с погрешностью 5-15% при $N = 10$
3. Скин-эффект учитывается приближенно, что физически корректно при малых $k\delta$
4. Увеличение $N > 20$ не улучшает точность из-за обусловленности матрицы
