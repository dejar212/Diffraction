# Теория дифракции электромагнитных волн на импедансной ленте

## 1. Постановка задачи

Рассматривается задача дифракции плоской электромагнитной волны на бесконечно тонкой импедансной ленте, расположенной в плоскости $z = 0$ на отрезке $[a, b]$ оси $x$

### 1.1. Падающее поле

Плоская волна, падающая под углом $\theta$ к оси $x$, описывается ф-цией

$$u_0(x, z) = e^{ik(x\cos\theta + z\sin\theta)}$$

где $k = \frac{2\pi}{\lambda}$, волновое число, $\lambda$, длина волны

### 1.2. Граничное условие Леонтовича

На импедансной поверхности выполняется граничное условие Леонтовича

$$u + \chi \frac{\partial u}{\partial n} = 0 \quad \text{на } z = 0, \, x \in [a,b]$$

где $\chi$, импедансный коэффициент, $n$, нормаль к поверхности (направление оси $z$)

Для проводника со скин-эффектом

$$\chi = k\delta(1 + i)$$

где $\delta$, толщина скин-слоя

Физический смысл: $\chi$ описывает отношение тангенциальных компонент электрического и магнитного полей на поверхности проводника

### 1.3. Уравнение Гельмгольца

В свободном пространстве поле $u(x,z)$ удовлетворяет ур-ю Гельмгольца

$$\Delta u + k^2 u = 0$$

где $\Delta = \frac{\partial^2}{\partial x^2} + \frac{\partial^2}{\partial z^2}$, оператор Лапласа

### 1.4. Условия излучения

На бесконечности поле должно удовлетворять условиям излучения Зоммерфельда т.е. рассеянное поле $u_{\text{рас}} = u - u_0$ должно представлять собой расходящуюся волну

$$u_{\text{рас}} \sim \frac{e^{ikr}}{\sqrt{r}}, \quad r \to \infty$$

## 2. Метод граничных интегральных ур-й

### 2.1. Интегральное представление решения

Решение задачи дифракции ищется в виде интеграла

$$u(x,z) = u_0(x,z) + \frac{i}{4} \int_a^b \varphi(t) H_0^{(2)}(k|r - r'|) \, dt$$

где:
- $H_0^{(2)}$, ф-ция Ханкеля 2-го рода нулевого порядка
- $r = (x,z)$, $r' = (t,0)$, точки наблюдения и интегрирования
- $\varphi(t)$, неизвестная плотность распределения источников на ленте

### 2.2. Функция Ханкеля

Ф-ция Ханкеля 2-го рода выражается через ф-ции Бесселя

$$H_0^{(2)}(x) = J_0(x) - iN_0(x)$$

где:
- $J_0(x)$, ф-ция Бесселя 1-го рода нулевого порядка
- $N_0(x)$, ф-ция Неймана (Бесселя 2-го рода)

Функция $H_0^{(2)}$ является фундаментальным р-нием ур-я Гельмгольца в 2D

$$\Delta H_0^{(2)}(k|r-r'|) + k^2 H_0^{(2)}(k|r-r'|) = -\frac{4i}{\pi}\delta(r-r')$$

### 2.3. Функция Бесселя $J_0(x)$

Ф-ция Бесселя 1-го рода вычисляется через степенной ряд

$$J_0(x) = \sum_{n=0}^{\infty} \frac{(-1)^n}{(n!)^2} \left(\frac{x}{2}\right)^{2n}$$

Реализация в программе использует итерационный алгоритм с критерием сходимости $|s_n| < \varepsilon$, где $\varepsilon = 10^{-4}$

### 2.4. Функция Неймана $N_0(x)$

Ф-ция Неймана выражается через $J_0(x)$ и вспомогательную ф-цию

$$N_0(x) = \frac{2}{\pi}\left(J_0(x)\ln\frac{x}{2} + Y_0(x)\right)$$

где

$$Y_0(x) = \sum_{n=1}^{\infty} \frac{(-1)^n}{(n!)^2} \left(\frac{x}{2}\right)^{2n} \psi_n$$

$$\psi_n = -\gamma + \sum_{k=1}^n \frac{1}{k}$$

$\gamma \approx 0.57721566$, постоянная Эйлера

## 3. Метод коллокации для СИУ с весовым базисом

### 3.1. Условие на ребре (условие Мейкснера)

Плотность тока $\varphi(t)$ на концах пластины имеет сингулярное поведение

$$\varphi(t) \sim \frac{1}{\sqrt{t - a}} \text{ при } t \to a, \qquad \varphi(t) \sim \frac{1}{\sqrt{b - t}} \text{ при } t \to b$$

Это фундаментальное физическое свойство: электрическое поле бесконечно на краях идеально проводящей полосы. Если не учитывать эту сингулярность, разложение по гладкому базису не сходится, коэффициенты растут, решение неустойчиво

### 3.2. Весовой базис

Неизвестная плотность представляется в виде

$$\varphi(t) = \frac{\psi(t)}{\sqrt{(t-a)(b-t)}}$$

где $\psi(t)$, гладкая ф-ция, раскладывается по полиномам Чебышева

$$\psi(t) = \sum_{j=0}^{N-1} y_j T_j^{[a,b]}(t)$$

Вес $w(t) = 1/\sqrt{(t-a)(b-t)}$, стандартный вес Чебышева на $[a,b]$

### 3.3. Квадратура Гаусса-Чебышева

Интегралы с весом вычисляются квадратурой Гаусса-Чебышева

$$\int_a^b \frac{f(t)}{\sqrt{(t-a)(b-t)}} \, dt \approx \frac{\pi}{M} \sum_{m=0}^{M-1} f(t_m)$$

Узлы квадратуры

$$t_m = \frac{b-a}{2}\cos\left(\frac{2m+1}{2M}\pi\right) + \frac{b+a}{2}, \quad m = 0,\ldots,M-1$$

Эта квадратура **точно** учитывает сингулярность веса. Число узлов $M = \max(60, 4N)$

### 3.4. Формирование СЛАУ

Подставляя разложение в граничное условие

#### Идеальный проводник ($\chi = 0$): условие $u(x_k, 0) = 0$

$$\sum_{j=0}^{N-1} y_j \cdot \frac{\pi}{M} \sum_{m=0}^{M-1} \frac{i}{4} H_0^{(2)}(k|x_k - t_m|) T_j(t_m) = -u_0(x_k, 0)$$

#### Импедансный проводник ($\chi \neq 0$): условие Леонтовича

$$\sum_{j=0}^{N-1} y_j \left[G_j(x_k) + \chi \frac{\partial G_j}{\partial n}(x_k)\right] = -\left[u_0(x_k,0) + \chi \frac{\partial u_0}{\partial n}(x_k,0)\right]$$

Нормальная производная вычисляется конечной разностью с $\delta z = \lambda/500$

### 3.5. Контроль сходимости

По подсказке преподавателя: при достаточно больших $N$ коэффициенты $y_j$ не должны сильно меняться. Старшие коэффициенты $|y_{N-1}|$ должны быть малы по сравнению с $|y_0|$. Нарастание старших коэффициентов означает неустойчивость. Если $\lambda < (b-a)$, нужно большее $N$

### 3.6. Физический смысл

Без учёта сингулярности на краях решение "разваливается": коэффициенты разложения не убывают, старшие коэффициенты нарастают (попытка гладкого базиса описать сингулярное решение). Квадратура Гаусса-Чебышева с весом решает эту проблему, т.к. сингулярность учтена **аналитически** в выборе базиса и квадратуры

## 4. Решение СЛАУ методом Гаусса

Полученная СЛАУ решается методом Гаусса с выбором главного элемента

### 4.1. Прямой ход

На каждом шаге $i = 0,\ldots,N-2$ выбирается максимальный по модулю элемент в столбце $i$ строк $i,\ldots,N-1$

$$\max_{k=i,\ldots,N-1} |A_{ki}| = |A_{mi}|$$

Строки $i$ и $m$ меняются местами

Затем выполняется исключение

$$A_{jk} \gets A_{jk} - \frac{A_{ji}}{A_{ii}} A_{ik}, \quad j > i, \, k > i$$

$$B_j \gets B_j - \frac{A_{ji}}{A_{ii}} B_i, \quad j > i$$

### 4.2. Обратный ход

Вычисляются неизвестные $y_k$ начиная с последней

$$y_{N-1} = \frac{B_{N-1}}{A_{N-1,N-1}}$$

$$y_i = \frac{1}{A_{ii}}\left(B_i - \sum_{j=i+1}^{N-1} A_{ij}y_j\right), \quad i = N-2,\ldots,0$$

### 4.3. Проверка устойчивости

Если $|A_{ii}| < \varepsilon_{\text{pivot}}$ (где $\varepsilon_{\text{pivot}} = 10^{-12}$), матрица считается вырожденной и метод возвращает код ошибки

## 5. Вычисление полного поля

После нахождения коэффициентов $y_j$ полное поле вычисляется как

$$u(x,z) = u_0(x,z) + \frac{i}{4} \sum_{j=0}^{N-1} y_j \int_a^b T_j^{[a,b]}(t) H_0^{(2)}(k\rho) \, dt$$

где $\rho = \sqrt{(x-t)^2 + z^2}$

Интеграл вычисляется той же трапецоидальной квадратурой, что и при формировании СЛАУ

$$\int_a^b T_j^{[a,b]}(t) H_0^{(2)}(k\rho) \, dt \approx \sum_{m=0}^{M-1} T_j^{[a,b]}(t_m) H_0^{(2)}(k\rho_m) \Delta t$$

## 6. Энергетический баланс через далёкое поле

### 6.1. Диаграмма направленности

В далёкой зоне рассеянное поле имеет вид

$$u_{\text{рас}}(r,\varphi) \sim f(\varphi) \frac{e^{-ikr}}{\sqrt{kr}}, \quad r \to \infty$$

где $f(\varphi)$, амплитуда далёкого поля

$$f(\varphi) = \frac{\sqrt{2\pi/k}}{4} e^{i\pi/4} \int_a^b \varphi(t) e^{ik\cos\varphi \cdot t} \, dt$$

### 6.2. Полное сечение рассеяния

$$\sigma_s = \int_0^{2\pi} |f(\varphi)|^2 \, d\varphi$$

### 6.3. Оптическая теорема

Связь полного сечения экстинкции с амплитудой рассеяния вперёд

$$\sigma_{\text{ext}} = \frac{4}{k} \text{Im}\left[f(\theta)\right]$$

где $\theta$, угол падения

Для идеального проводника $\sigma_{\text{ext}} = \sigma_s$. Для импедансного: $\sigma_{\text{ext}} = \sigma_s + \sigma_a$

### 6.4. Разделение отражённой и прошедшей энергий

Рассеянная энергия делится по полупространствам:
- **Отражённая**: углы $\varphi$ с $\sin\varphi \geq 0$ (полупространство $z > 0$)
- **Прошедшая** (дифрагированная): углы с $\sin\varphi < 0$ (полупространство $z < 0$)

### 6.5. Поглощённая энергия

Для импедансной поверхности поглощённая мощность

$$\sigma_a = \frac{k \cdot \text{Re}(\chi)}{2} \int_a^b |u(x,0)|^2 \, dx$$

## 7. Проверка точности решения

### 7.1. Граничное условие Леонтовича

Погрешность выполнения граничного условия

$$\varepsilon_{\text{гр}} = \frac{1}{M+1} \sum_{i=0}^M \frac{|u(x_i,0) + \chi \frac{\partial u}{\partial z}(x_i,0)|}{\max(|u(x_i,0)|, 0.1)}$$

где $x_i = a + i\frac{b-a}{M}$

Погрешность зависит от N и параметра $\chi$

### 7.2. Уравнение Гельмгольца

Невязка ур-я Гельмгольца в свободном пространстве

$$\varepsilon_{\text{Гельм}} = \frac{|\Delta u(x_0,z_0) + k^2 u(x_0,z_0)|}{k^2|u(x_0,z_0)| + 10^{-10}}$$

где $(x_0,z_0) = (b + \lambda, \lambda)$, контрольная точка вне ленты

Лапласиан вычисляется численно с шагом $h = \frac{\lambda}{100}$

$$\Delta u \approx \frac{u(x+h,z) + u(x-h,z) + u(x,z+h) + u(x,z-h) - 4u(x,z)}{h^2}$$

### 7.3. Энергетический баланс

Дисбаланс энергии

$$\varepsilon_{\text{эн}} = \frac{|E_{\text{пад}} - (E_{\text{отр}} + E_{\text{прош}} + E_{\text{погл}})|}{E_{\text{пад}}}$$

В текущей реализации $\varepsilon_{\text{эн}} = 0$ т.к. $E_{\text{прош}}$ вычисляется из ЗСЭ

## 8. Численная реализация

### 8.1. Параметры дискретизации

- $N$, кол-во членов разложения Чебышева (по умолчанию 10)
- $M = \max(80, 4N)$, кол-во узлов трапецоидальной квадратуры
- $N_\varphi = 360$, кол-во углов для интегрирования далёкого поля

### 8.2. Сложность алгоритма

- Формирование матрицы (идеальный проводник): $O(N^2 M)$
- Формирование матрицы (импедансный): $O(2 N^2 M)$ (два прохода: $z=0$ и $z=\delta z$)
- Решение СЛАУ: $O(N^3)$
- Вычисление поля: $O(NM)$ на одну точку
- Далёкое поле: $O(N_\varphi \cdot NM)$

### 8.3. Точность вычислений

- Полиномы Чебышева: машинная точность ($\sim 10^{-15}$)
- Функции Бесселя: $\varepsilon = 10^{-4}$ (ряд до 10000 членов)
- Квадратуры: $O(\Delta t^2)$ для гладких функций
- Решение СЛАУ: машинная точность с пивотингом
- Граничное условие: погрешность 1.5-3.5% при $N = 12$

## 9. Учет скин-эффекта

### 9.1. Прямой учёт в СЛАУ

Для импедансного граничного условия $u + \chi \partial u / \partial n = 0$ модифицируется СЛАУ

Элементы матрицы

$$A_{kj} = G_j(x_k, 0) + \chi \frac{\partial G_j}{\partial n}(x_k, 0)$$

Правая часть

$$B_k = -\left[u_0(x_k, 0) + \chi \frac{\partial u_0}{\partial n}(x_k, 0)\right]$$

Нормальная производная вычисляется конечной разностью с шагом $\delta z = \lambda/500$

### 9.2. Импедансный коэффициент

$$\chi = k\delta(1 + i)$$

При $\chi = 0$ (идеальный проводник) СЛАУ сводится к стандартному случаю $u(x_k,0) = 0$

### 9.3. Область применимости

1. $k\delta \lesssim 1$ (толщина скин-слоя сравнима или меньше длины волны)
2. $k(b-a) \sim 1$ (ширина ленты порядка длины волны)
3. $8 \leq N \leq 20$ (число членов разложения)

## 10. Выводы

1. Метод прямой коллокации с полным ядром $H_0^{(2)}$ корректно решает задачу дифракции
2. Граничное условие $u=0$ выполняется с погрешностью 1.5-3.5% при $N = 12$
3. Условие Леонтовича учитывается непосредственно в СЛАУ
4. Энергетический баланс проверяется через оптическую теорему
5. Конвергенция по $N$ стабильна, NaN не наблюдается при $M = \max(80, 4N)$
