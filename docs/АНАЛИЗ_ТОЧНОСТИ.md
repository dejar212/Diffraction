# Анализ точности решения задачи дифракции

## 1. Обзор проблем предыдущей реализации

### 1.1. Метод Галёркина с регуляризованным ядром

Исходная реализация использовала метод Галёркина с выделением логарифмической особенности ядра $H_0^{(2)}(k|t-x|)$

Регуляризованное ядро:

$$r(t,x) = -\frac{\pi i}{2} H_0^{(2)}(k|t-x|) + \ln|t-x|$$

Диагональные коррекции:

$$R_0 = \pi^2 \ln(b-a), \quad R_k = \frac{\pi^2}{2(k+1)}$$

### 1.2. Диагностика

Тестирование выявило критическую проблему:

- СЛАУ решалась точно: $\|Ay - B\| \sim 10^{-15}$
- Но физическое граничное условие $u(x,0) = 0$ **не выполнялось**: $|u(x,0)| \approx 2.0$

Причина: коэффициенты $R_k$ не обеспечивали корректную компенсацию выделенной логарифмической особенности

### 1.3. Другие проблемы

- NaN при $N > 10$: недостаточное кол-во узлов квадратуры ($M = 20$ фиксировано)
- Энергия порядка $10^{20}$: некорректные формулы с ad-hoc масштабными множителями
- Погрешность ГУ ~100% при любых углах

## 2. Новый метод: прямая коллокация

### 2.1. Суть метода

Вместо метода Галёркина с регуляризацией используется прямая коллокация:

1. Точки коллокации — нули полинома Чебышева $T_N$
2. Ядро $H_0^{(2)}$ используется **полностью** (без выделения особенности)
3. Трапецоидальная квадратура с $M = \max(80, 4N)$ узлами

### 2.2. Результаты тестирования

При $a=-1$, $b=1$, $\lambda=1$, $N=12$, $M=80$:

| Угол | Погрешность ГУ |
|------|----------------|
| 10°  | 1.46%          |
| 30°  | 1.80%          |
| 45°  | 2.21%          |
| 60°  | 2.71%          |
| 80°  | 2.06%          |

### 2.3. Сравнение методов

| Метод                               | Погрешность ГУ | СЛАУ     |
|--------------------------------------|----------------|----------|
| Галёркин + регуляризация             | ~100%          | 1e-15    |
| Прямая коллокация + H0 полное        | ~9-31%         | 1e-14    |
| Чебышев. коллокация + трапеция M=80  | **1.5-3.5%**   | 1e-14    |

## 3. Энергетический баланс

### 3.1. Проблема предыдущей реализации

Энергия вычислялась через интеграл поля в ближней зоне с эмпирическими масштабными коэффициентами. Результаты: значения порядка $10^{20}$ при некоторых углах

### 3.2. Новый подход: далёкое поле

Рассеянная энергия вычисляется через диаграмму направленности $f(\varphi)$:

$$\sigma_s = \int_0^{2\pi} |f(\varphi)|^2 \, d\varphi$$

Верификация через оптическую теорему:

$$\sigma_{\text{ext}} = \frac{4}{k} \text{Im}[f(\theta)]$$

Для идеального проводника: $\sigma_{\text{ext}} = \sigma_s$ (нет поглощения)

### 3.3. Преимущества

- Физически обоснованные величины (сечения рассеяния)
- Не зависит от выбора области интегрирования
- Верифицируется оптической теоремой
- Быстрое вычисление ($O(N_\varphi \cdot NM)$ вместо $O(N_z \cdot NM \cdot 3)$ для Пойнтинга)

## 4. Импедансное граничное условие

### 4.1. Прямой учёт в СЛАУ

Условие Леонтовича $u + \chi \partial u / \partial n = 0$ учитывается непосредственно при формировании СЛАУ:

$$A_{kj} = G_j(x_k, 0) + \chi \frac{\partial G_j}{\partial n}(x_k, 0)$$

Нормальная производная вычисляется конечной разностью

### 4.2. Ожидаемые результаты

- При $\chi = 0$: идеальный проводник, погрешность ГУ 1.5-3.5%
- При $\chi \neq 0$: ненулевое поглощение, коэффициенты Чебышева отличаются

## 5. Рекомендации

1. Использовать $N = 10-16$ для оптимального баланса точности и скорости
2. Увеличение $N > 20$ может ухудшить обусловленность
3. Для конечной полосы **прошедшая энергия ненулевая** даже для идеального проводника (дифракция вокруг краёв)
4. Верификация через оптическую теорему позволяет контролировать корректность решения
