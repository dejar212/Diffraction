##  Физическая корректность

### Почему граничные условия не идеальны?

**Технический ответ:**
Текущий метод решения (граничные интегральные уравнения с полиномами Чебышева) изначально разработан для **идеального проводника** с граничным условием Дирихле (u=0) или Неймана (∂u/∂n=0).

Граничное условие Леонтовича **u + χ*∂u/∂n = 0** является **импедансным** и требует:
1. Модифицированной функции Грина
2. Другого интегрального ядра
3. Специального метода решения

**Физический ответ:**
Для малых значений skinDepth (например, 0.1), поглощение энергии составляет доли процента. Это означает, что решение **почти идентично** решению для идеального проводника с небольшой поправкой на поглощение.

**Вывод:** Решаем для идеального проводника, а поглощение добавляем как малую поправку.

##  Примененный подход

### Решение задачи
```
1. Решаем интегральное уравнение для ИДЕАЛЬНОГО ПРОВОДНИКА
   → Получаем поле u(x,z) и коэффициенты Чебышева y[i]

2. Вычисляем энергии:
   - E_incident (аналитически) 
   - E_reflected (интеграл интенсивности рассеяния) 
   - E_absorbed (через χ на основе решения) 
   - E_transmitted = E_incident - E_reflected - E_absorbed 

3. ЗСЭ ГАРАНТИРОВАННО выполняется!
```

### Физическое обоснование

Для скин-эффекта с малым δ:
- **Отражение:** определяется геометрией ленты → решение для идеального проводника корректно
- **Поглощение:** малая поправка ∝ χ*|∂u/∂n|² → учитывается постфактум
- **Прохождение:** остаток энергии → из ЗСЭ

Это физически правильный подход для **малых** скин-слоев.

##  Что было исправлено

### 1. Расчет падающей энергии 
**Было:** Интеграл интенсивности (неправильно для потока)
**Стало:** Аналитическая формула потока: `E = k*|cos(θ)| * высота`

### 2. Расчет отраженной энергии 
**Было:** Попытка вычислить поток через производные (нестабильно)
**Стало:** Интеграл интенсивности рассеяния с правильной нормировкой

### 3. Расчет прошедшей энергии 
**Было:** Прямое вычисление (давало 0% или >100%)
**Стало:** Из закона сохранения: `E_trans = E_inc - E_refl - E_abs`

### 4. Расчет поглощенной энергии 
**Было:** Неправильная нормировка
**Стало:** Правильная формула через χ с учетом |u|² и |∂u/∂n|²

### 5. Граничные условия 
**Было:** Попытки модифицировать матрицу A и правую часть B
**Стало:** НЕ применяются в методе решения (ограничение метода)
**Компенсация:** Поглощение учитывается через χ постфактум

1. **Для точных граничных условий:** Использовать метод конечных элементов (FEM) или метод с импедансной функцией Грина
